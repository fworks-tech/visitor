# Environment plates

Background plates for the aperture view system (`assets/data/view_presets.json`).

- 1280x720 JPG, quality 88, no people, no UI, no border.
- Generated for this project as first-pass plates. Replace with painted or
  photographed plates when the art pass allows; keep the same framing: the
  center must have room for a 1.8 m body at 1.35 m from the camera.
- No third-party license attaches to these plates. They are original generated
  assets for DEEPTALES.
- Keep the bottom third readable: the body and the dialogue box sit there.
