# Shared Branding (Phase 6)

Studio-level brand kit. Every generated game inherits these; per-game
palettes come from the generator's 5 style presets. Studio colors
(Void/Bone/Threshold/Rust) are for branding and the DEEPTALES stamp —
never replace a game's style palette with them.

## Studio palette

| Name | Hex | Use |
|---|---|---|
| Void | `#0A0C0B` | Backgrounds, feature graphic, store art |
| Bone | `#E6E1D5` | Wordmark, primary text on brand materials |
| Threshold | `#3E5C46` | Signal accent — interactive highlights, links |
| Rust | `#6E2B26` | Warnings, consequences — sparingly |

Canonical lockup: arched door emblem above the distressed serif wordmark
(`brand/logo_wordmark.png`), bone-on-void with subtle grain.

## Credits template (paste into each game's store listing + splash)

```
{TITLE} — a DEEPTALES game.

Story, art direction and code: Fabio Ritzel Borges.
Generated with DEEPTALES v{VERSION} ({genre}, {style}).
Audio: synthesized in-house unless ATTRIBUTIONS.md says otherwise.

No ads. No accounts. No data collected.
```

## Icon recipe per style

Base: `brand/app_icon.png` (door emblem). The generator's `derive_icon()`
re-palettes it to the game's style preset at generation time:

| Style | Recipe note |
|---|---|
| dark_horror | Desaturated bone emblem on near-black; keep contrast high at 48px |
| analog_green | Green-monochrome pass; emblem reads as phosphor |
| amber_terminal | Amber-on-black; test legibility on dark wallpapers |
| cold_noir | Cold blue-grey; deepen shadows, keep emblem outline |
| vhs_red | Red-shifted; verify no bleed at small sizes |

Adaptive icon: emblem as foreground on Void; no text in the icon.
Export PNG at 512, 192, 144, 96, 72, 48 — verify the 48px render first.

## Launch screens

1. **Splash stamp** (automatic): `scenes/DeeptalesStamp.tscn` — door emblem
   + "Generated by DEEPTALES", instanced into the splash at generation.
2. **Title screen**: game title in style palette, threshold motif (door /
   pier / line — one image, no collage), single "Begin" affordance.
3. Never show engine logos, debug text, or TODO markers past the stamp.

## Store art rules

Feature graphic 1024×500: emblem + wordmark + tagline only (see
`STORE_LISTING.md`). Screenshots on-device, portrait, no editor chrome.
Trailer beat sheet (M6-5, when needed): hook (5s) → loop (20s) → dread
(15s) → title card — pull art from the game, never concept art.
